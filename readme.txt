== Description ==
Pecodex Security provides "Caveman Ultra" level security for your WordPress site. 

Our comprehensive suite of security features includes:
* Deep Malware Scanner
* Web Application Firewall
* Live Radar Map
* GeoIP Blocking
* Webhooks
* 2FA/WebAuthn
* Zero Trust Session Hardening
* Database schema backups

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/pecodex-security` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
